# QCortado

QCortado is a desktop application for setting up, running, monitoring, and reviewing computational materials workflows.

It provides a guided interface for Quantum ESPRESSO and WIEN2k workflows, with project organization, HPC-oriented execution tools, live task output, and result viewers for common electronic-structure outputs.

## Documentation

Full documentation is available at:

https://jakescally.com/qcortado/

Use the docs for installation, setup, workflow walkthroughs, and current feature details.

## What It Helps With

- Creating and managing calculation projects
- Preparing engine-specific workflows without hand-writing every input file
- Running local or remote HPC jobs from a consistent interface
- Monitoring active calculations and reviewing completed task output
- Visualizing structures, bands, density of states, phonons, transport data, and related artifacts
- Keeping Quantum ESPRESSO and WIEN2k work organized in one application

## Supported Engines

- Quantum ESPRESSO
- WIEN2k

## Development

QCortado is built with Tauri, Rust, TypeScript, and React. Developer setup and build notes live in the full documentation.
